DEFECT 1 — record destinations were parsed but never reported
RecordCompare and its JSON rendering carried source addresses and lengths but
not each record's dst. A synthetic destination change was invisible in both
Markdown and JSON, so a runtime-load-address change could have gone
unreported. RecordCompare now carries installed_dst/vendor_dst plus
addr_changed, dst_changed and checksum_changed. Reproduction of the reviewer's
case, slot 1 destination forced to 0x18001000:
$ python3 - <<'PY'
import struct, sys
sys.path.insert(0, 'tool')
import compare_firmware_images as c, falchion_image as fi
data = bytearray(open('dumps/vendor/M605_V01_00_58.bin','rb').read())
table = fi.FWIN_OFF + fi.FWIN_REC0_OFF
struct.pack_into('<I', data, table + fi.REC_STRIDE + 12, 0x18001000)
left = fi.ImageView(bytes(data[0x10000:0x7c000]), 0x10000)
right = fi.ImageView(bytes(open('dumps/vendor/M605_V01_00_58.bin','rb').read()), 0)
result = c.compare(left, right)
slot1 = [r for r in result.records if r.slot == 1][0]
print('model   dst installed=0x%08x vendor=0x%08x changed=%s'
      % (slot1.installed_dst, slot1.vendor_dst, slot1.dst_changed))
entry = [e for e in c.to_dict(result)['records'] if e['slot'] == 1][0]
print('json    dst installed=0x%08x vendor=0x%08x changed=%s'
      % (entry['installed']['dst'], entry['vendor']['dst'], entry['dst_changed']))
line = [l for l in c.markdown_lines(result) if l.startswith('| 1 |')][0]
print('markdown', line)

DEFECT 2 — provenance was verified after analysis, not before
main() called compare() and only then check_sources(), so an unknown source
was parsed, hashed and diffed before being judged, and a malformed unknown
input surfaced as a structural error rather than an unknown-source refusal.
check_sources() now takes the two ImageViews and runs before compare(); it
returns the unknown-source names to proceed, or None to refuse.
$ python3 - <<'PY'
import pathlib, sys, tempfile
sys.path.insert(0, 'tool')
import compare_firmware_images as c
data = bytearray(open('dumps/vendor/M605_V01_00_58.bin','rb').read())
data[0x41000] ^= 0xff
tmp = pathlib.Path(tempfile.mkdtemp()) / 'unvouched.bin'
tmp.write_bytes(bytes(data[0x10000:0x7c000]))
calls = []
original = c.compare
def tripwire(*a, **k):
    calls.append(a)
    raise AssertionError('compare() must not run')
c.compare = tripwire
code = c.main(['--installed', str(tmp), '--vendor', 'dumps/vendor/M605_V01_00_58.bin'])
c.compare = original
print('exit', code, 'compare() calls:', len(calls))
tmp.unlink()

  * Record diff ranges still cover the common prefix only, by design; the
    one-sided tail is now reported as its own span.
