3. THE COMPLETE PHYSICAL-SWITCH PATH

Installed FUN_180068aa reads GPIO identifier 0x47 through FUN_18010a18.
FUN_18010850 splits that identifier into group 4 and bit 7 and resolves the
group's MMIO base through a RAM table. FUN_18010a18 returns a binary MMIO
sample. This identifies a firmware GPIO code, not a PCB pad or port letter.

Current profile = *(byte*)0x1801e6d6 (device header +6).
Current global word = *(uint32*)(0x18024f0c + profile*4).
Shared mismatch counter = *(uint32*)0x1801e778 (key-state struct +0x44).

Instruction-derived flow:
  180068ae  2047             GPIO identifier 0x47
  180068c4  f3c0 1340        extract current-profile bit 5
  180068b6                  invert first sample with XOR 1
  180068ca..180068cc         compare inverted sample with bit 5
  18006910                  equal -> reset counter and return
  180068ce..180068d2         mismatch -> increment uint32 counter
  180068d4  42b2             compare count with caller threshold
  180068d6  d91c             return while count <= threshold (unsigned)
  180068d8..180068dc         reset counter and read GPIO again
  180068ea  f020 0020        nonzero resample -> clear bit 5
  1800690a  f040 0020        zero resample -> set bit 5
  180068f6  f845 0021        write selected profile word, preserve other bits
  180068f0                  extract resulting bit into report argument r3
  180068fc  2076             report opcode 0x76
  180068fe                  FUN_18004498(0x76,0,0,bit5)
  18006906                  tail-call runtime refresh FUN_180089a8

Thus GPIO zero means enabled, GPIO one disabled. The captured owner's ON/OFF
actions in log 137 establish the physical label corresponding to those bits.
The extra sample matters: if it bounces back at acceptance, the function can
queue the unchanged state. A status report alone is not proof of a new motion.

6. INITIALIZATION, RELOAD, WRITERS AND PERSISTENCE BOUNDARY

The enable bit lives in a six-profile global-word table. A profile selection
changes which word the poll and key-scan consumer read. FUN_1800e64e restores
the global block through the storage descriptor at 0x1801e96c in inspected
initialization paths (18000df4/18000e38). This can replace the bit along with
other whole-block contents. Actuation repair masks bits 9..15 and preserves 5.

Factory resets replace entire words with bit 5 clear:
  single-profile store 18001d8e, initialized from 0x10 + function bits +0x1400;
  all-profile store 18001e24, also initialized with top/bottom defaults.
The inspected storage completion paths refresh runtime settings but do not
directly queue 0x76. The periodic GPIO poll subsequently reconciles whichever
word is now selected. If its bit already agrees, the poll resets the counter
and produces no status; if it disagrees, it can queue a report after debounce.
This explains the capability to report after profile switching without new
motion. It does NOT establish an unconditional resend after every switch.

FUN_180089a8 packs enable into runtime byte bit 2, alongside global bits 2/3
in runtime bits 1/0, then calls FUN_1800aba4 and FUN_1800cf98. The switch poll
does not directly mark storage dirty or invoke the persistence helper
FUN_1800e7ee. Other whole-global-block save paths can include the RAM bit.
Therefore lever-only persistence across power loss remains unproven.

Writer scope: GPIO mutation, full-block restoration and factory reset were
inspected, along with direct references and several global-word consumers.
This is a supported lifecycle explanation, not proof against every possible
indirect writer. GPIO values in a real boot were not measured by this session.
The alternate multifunction side-control HAL names remain unmapped; do not
