  * No function meaning is inferred. Confidence tiers describe evidence
    strength, not correctness, and a tentative pairing is a lead for manual
    review rather than an established correspondence.

    decompressor was not reimplemented, so those runtime bytes are mapped,
    not known.

    not established here.
  * Data-gap comparison is aligned by the matched functions bracketing each
