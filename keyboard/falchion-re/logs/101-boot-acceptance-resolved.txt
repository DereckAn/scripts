FACTS ESTABLISHED IN THIS PHASE
  1. FUN_000029d4 is a recovery key-combination poll, not an integrity
     check. It ticks the bootloader's own scan, and returns 1 — blocking
     the boot — once the pattern at RAM 0x18012ac8 (+0x0 == 0xa0 and
     +0x10 == 0x100) has held for 30 consecutive samples. A custom image
     has to satisfy nothing here.
  2. The top-level comparison is against DAT_00007f98 = 0x60011000. The
     SN_FWIN +0x10 entry pointer must equal that constant exactly, so the
     entry image CANNOT be relocated. This is a hard builder rule.
  3. A third gate, FUN_00002a44, was not previously named. It reads
     0x20000ffc, compares it with 0x73207320, and when equal clears the
     word and returns 1 — a one-shot software-requested bootloader-entry
     flag, consistent with logs 87 and 88.
  4. FUN_000026d0(0x6c000) sums from DAT_0000277c = 0x60010000, so the
     region it guards is exactly the application region 0x10000..0x7c000,
     with the guard word at 0x7bffc. Base and length are now read from
     bootloader constants rather than assumed.
  5. The transfer of control is a copy and a system reset, not a branch.
     FUN_00007fa8 parks the entry in VTOR+0x1c; BootHandoff, scatter-loaded
     from program 0xcdfc to RAM 0x18010000, masks interrupts, copies a
     fixed 0x10000 bytes from the entry address to ADDRESS 0, writes AIRCR
     with VECTKEY and SYSRESETREQ, and spins until the reset lands.
  6. That explains three previously inferred things: Candidate A is linked
     at 0 because it genuinely runs there; the SN_FWIN record's +0xc word
     is not a load destination, since the destination is the constant 0 in
     the call and FUN_0000511c never reads +0xc; and the 0xff fill from
     0x168ac to 0x21000 sits inside the copied window, because the copy
     length is fixed regardless of record slot 0's 0x58ac.
  7. There is no signature check, no cryptographic constant, no version or
     rollback rule, no device-ID gate and no configuration-dependent gate
     anywhere in the bootloader.
  8. The complete accept expression is four gates: two environmental
     (recovery combination, RAM entry flag) and two image properties
     (entry pointer constant, application word-sum), on top of the
     per-container checks FUN_00008000 already performed — SN_FWIN magic,
     entry initial-SP in RAM, and every nonzero-length record slot's
     chunked-CRC sum.
