# Restore my Hyprland + Caelestia setup on a fresh CachyOS

Rebuilds the desktop after a format: **ML4W base config + Caelestia shell +
Quakboard clipboard**, with waybar/swaync/rofi/walker removed.

> Use the **same username (`dereck`)** — a few paths are absolute (wallpaper,
> Quakboard AppImage). Quakboard regenerates its own Hyprland bind on first
> launch, so that part self-heals.

The files in this folder are an **overlay** on top of a stock ML4W install —
they are NOT a full config. Install ML4W first, then drop these on top.

---

## 1. Install the ML4W dotfiles (the base)

ML4W provides the Hyprland config framework + the everyday keybind scripts
(terminal, browser, file manager, calculator, emoji picker, theme toggles).

    # https://github.com/mylinuxforwork/dotfiles  (follow its installer)
    # It creates ~/.mydotfiles/com.ml4w.dotfiles.stable and symlinks
    # ~/.config/hypr, ~/.config/ml4w, ~/.config/waybar into it.

Log into Hyprland once to confirm the stock ML4W desktop works.

## 2. Install packages

    # AUR helper (CachyOS ships paru; yay also fine)
    paru -S --needed - < pkglist-aur.txt
    paru -S --needed - < pkglist-explicit.txt   # repo + AUR; --needed skips installed

Key ones this setup depends on: `caelestia-shell caelestia-cli quickshell-git
hyprland hyprshot cliphist hypridle qt6-wayland ttf-material-symbols-variable
ttf-cascadia-code-nerd`. (Many of the 231 explicit pkgs are CachyOS defaults.)

Protect qt6-wayland so an orphan cleanup never removes it (Caelestia needs it):

    sudo pacman -D --asexplicit qt6-wayland

## 3. Overlay our custom config

    cp config/hypr/custom.conf     ~/.config/hypr/conf/custom.conf
    cp config/hypr/autostart.conf  ~/.config/hypr/conf/autostart.conf
    # quakboard.conf is auto-generated by the app in step 5; copy only if needed:
    # cp config/hypr/quakboard.conf ~/.config/hypr/quakboard.conf

## 4. Turn waybar off (Caelestia is the bar)

    touch ~/.config/ml4w/settings/waybar-disabled
    hyprctl reload

## 5. Quakboard (clipboard)

    mkdir -p ~/Applications
    # copy Quakboard-<ver>-Linux-x64.AppImage into ~/Applications/ and chmod +x it
    chmod +x ~/Applications/Quakboard-*.AppImage
    ~/Applications/Quakboard-*.AppImage &   # first launch regenerates quakboard.conf + Super+V bind
    # (optional) restore clipboard history + saved hotkey:
    #   copy your backup of ~/.local/share/com.dereckan.quakboard/ into place

## 6. Wallpaper + theme

    caelestia wallpaper -f ~/path/to/your-wallpaper.jpg   # sets wallpaper + generates theme

## 7. Remove the retired packages (optional, matches this setup)

    sudo pacman -Rns waybar swaync walker rofi rofi-wayland

## 8. System-level tweaks (manual — not in dotfiles)

See `HYPRLAND-RECOVERY.md` in this folder for: faillock/sudo fix,
sudo-attempts PAM script, BIOS fan-curve smoothing, EXPO/CMOS notes.

---

## What each tracked file is

- `config/hypr/custom.conf` — all my personal Hyprland settings + Caelestia
  keybinds + the ML4W keybinds I disabled. This is the important one.
- `config/hypr/autostart.conf` — ML4W autostart with the shell/daemons
  (swaync, ml4w-autostart, listeners, wallpaper app) disabled.
- `config/hypr/quakboard.conf` — Quakboard's managed bind (usually auto-made).
- `pkglist-explicit.txt` / `pkglist-aur.txt` — package snapshot.
- `HYPRLAND-RECOVERY.md` — full migration + repair history and system fixes.

## Keeping this in sync

After changing anything in `~/.config/hypr`, re-copy into this folder and commit:

    cp ~/.config/hypr/conf/custom.conf    config/hypr/custom.conf
    cp ~/.config/hypr/conf/autostart.conf config/hypr/autostart.conf
    cp ~/HYPRLAND-RECOVERY.md             HYPRLAND-RECOVERY.md
    pacman -Qqe > pkglist-explicit.txt; pacman -Qqm > pkglist-aur.txt
    git add linux && git commit -m "linux: sync hypr config"
